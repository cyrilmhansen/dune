## Native algorithm and machine result

`Pli80_host.Mapped_lookup.high_attribute` extends the existing mapped/low-attribute
family without merging its separate scratch/read channels. It performs:

1. Publish C to **AE47**.
2. Read the little-endian **AE47/AE48** pair, retaining the actually-read neighbor
   AE48 as discarded metadata; zero-extend only the low byte for addressing.
3. Freshly read `packed=byte[1B4B+saved_C]`.
4. Mask with **FC**, clear incoming carry, and perform **three carry-aware right
   shifts** in order, retaining each value and outgoing carry.
5. Mask with **07** to obtain high3.

The algorithm visibly preserves the historical ANI FC / RAR / RAR / RAR / ANI07
sequence; `(packed>>3)&7` is used as an independent test equation, not as the
implementation. Low3 and high3 remain distinct operations with distinct scratch.

The bridge returns A=high3, BC=1B4B, HL=1B4B+inputC, DE preserved. Final flags come
from final ANI07: S=0, Z from result0, P from even result parity, CY=0. **Intel8080
ANI AC is `(input OR operand).bit3`**, so final AC is third-shift.bit3, equivalently
original packed.bit6. It is neither unconditional true nor derived from result
high3. This agrees with the established ALU/CPU model, all 256 packed bytes at
all 32 incoming flag combinations, and every natural snapshot. No archaeology
contract correction was needed.

`Pli80_host.Auxiliary.read_secondary` extends the existing primary read/publication
family while retaining public naming compatibility. It performs:

1. Publish position C to **AE3B**.
2. Actually read little-endian **AE3B/AE3C**, retaining the discarded AE3C neighbor.
3. Freshly read `j=byte[AA1F+saved_position]`.
4. Freshly read **byte[AD9D+j]** and return it.

Only AE3B is written. The bridge returns A=selected byte, BC=zero-extended j,
HL=AD9D+j, DE preserved. NZPA are **entry flags**, not flags generated by the
returned byte; CY=0 from final DAD B. Every natural invocation confirms this.

Both primitives use the same Bytes.t-backed State as the existing native surface.
Tests prove execution-time packed-table changes, fresh map/secondary reads,
independent AD08/AD9D channels at different addresses and true physical overlap
when numeric addresses coincide (`AD08+149 == AD9D+0`). No persistent logical
arrays or unproved global table immutability are introduced. Selected secondary
addresses overlapping its own carrier AE3B/AE3C (j158/159), accessed protected
stack/code and invalid addresses/bytes are rejected under the declared scope;
there is no invented whole-table disjointness or inferred capacity.
